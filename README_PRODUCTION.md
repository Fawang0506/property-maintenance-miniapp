# 生产上架准备说明

本仓库已升级为生产版本，包含用户认证、图片上传、工单处理流程及云函数权限校验。请按下面步骤准备上线：

1. 开通并绑定微信云开发环境
   - 在微信公众平台 / 微信开发者工具中创建并绑定云环境。
   - 将 `app.js` 中的 `wx.cloud.init({ env: 'your-cloud-env-id' })` 替换为你的环境 ID，或在开发者工具中设置默认环境。

2. 部署云函数
   - 在微信开发者工具中，右键 `cloudfunctions/maintenance` -> 上传并部署。
   - 先运行 `cloudfunctions/init` 来创建 settings/global 文档（用于保存管理员列表）。

3. 创建云数据库集合
   - 在云开发控制台创建 `maintenance`、`users`、`settings` 集合（云函数在写入时会自动创建，建议先创建并建立索引）。
   - 为 `maintenance` 集合创建索引：
     - createdAt: 倒序查询时用到
     - creatorOpenId
     - status

4. 配置管理员
   - 在云数据库 `settings` 集合中找到 `_id = 'global'` 的文档，编辑 `admins` 数组，添加管理员 openId。
   - 或者使用云函数 `init` 先初始化，再手动填入 admins。

5. 小程序端设置
   - 在微信开发者工具中打开项目，确保 `project.config.json` 中 `cloudfunctionRoot` 指向 `./cloudfunctions/`。
   - 在开发过程中可先调用 `/pages/login` 执行一键登录并创建用户。

6. 上架审核注意项
   - 填写小程序隐私协议与用户数据说明（若上传图片/收集手机号等信息请明确用途）。
   - 如需订阅消息/推送，按微信官方要求配置并在审核材料里说明。
   - 若使用第三方服务（短信/电话），需在隐私政策中声明第三方依赖。

7. 后续建议
   - 为云函数添加更严格的输入校验与参数白名单。
   - 为图片提供 CDN 加速和防盗链策略（若需要对外访问）。
   - 添加操作日志（logs 集合）用于审计。
