# 物业维护项目运维与上线说明

## 1. 环境准备

- 微信开发者工具已绑定小程序项目。
- 微信云开发环境已创建，并确认可用。
- 需要先在云控制台中初始化数据库集合：`maintenance`、`users`、`settings`。

## 2. 管理员与权限初始化

在云开发数据库中创建/更新 `settings/global` 文档：

```json
{
  "_id": "global",
  "admins": ["<openid>"],
  "adminTokens": ["<strong-token>"]
}
```

说明：
- `admins` 用于检查管理员权限。
- `adminTokens` 用于后台登录校验。
- 在生产环境中请不要把真实 token 提交到公开代码仓库。

## 3. 订阅消息配置

在微信小程序后台中配置订阅消息模板：

- 报修状态更新通知
- 指派通知
- 处理完成通知

模板 ID 需要在云函数 `notify` 里替换成真实值，示例：

```js
const templateId = 'TEMPLATE_ID_HERE';
```

## 4. 审核前检查清单

- 隐私政策已上线并可访问
- 小程序功能说明完整准确
- 图片和位置信息说明明确
- 微信订阅消息模板已审核通过
- 管理后台权限已校验
- 云函数和数据库已上线
- 老版本功能回归测试通过

## 5. 发布建议

- 先发布体��版，收集真实测试反馈。
- 修正功能、权限和隐私问题后再提交审核。
- 审核通过后执行正式发布。
- 版本更新后建议补充发布说明，便于故障排查。

## 6. 灾备和故障排查

- 使用云函数日志观察报修创建、更新和通知发送异常。
- 若管理员后台无法访问，检查 `settings/global` 是否存在且 token 正确。
- 若状态更新失败，优先检查 `maintenance` 集合权限和云函数代码。
- 若图片上传失败，检查云存储权限与图片大小限制。
