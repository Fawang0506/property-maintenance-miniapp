# 上线前审核 Checklist

## 一、基础信息
- [ ] 小程序名称、简介、头像、类目正确
- [ ] 备案信息、客服信息齐全
- [ ] 小程序有明确的功能介绍和服务范围
- [ ] 公告与协议页面已准备好

## 二、隐私与数据合规
- [ ] 隐私政策页面已上线，且链接可见
- [ ] 明确说明收集、使用、存储、共享、删除的范围
- [ ] 若收集图片/位置信息，已说明用途和存储时长
- [ ] 用户授权说明清晰、可回溯

## 三、通知与推送
- [ ] 订阅消息模板已申请并测试通过
- [ ] 用户授权订阅流程已实现
- [ ] 维修状态变更通知模板已配置

## 四、功能验证
- [ ] 登录/注册流程可用
- [ ] 报修创建、列表、详情、状态更新流程已测试
- [ ] 图片上传/删除/显示正常
- [ ] 管理员权限校验有效
- [ ] 导出功能和筛选功能已测试

## 五、技术与稳定性
- [ ] 云函数已部署并测试通过
- [ ] 云数据库索引已建好
- [ ] 关键路径无明显报错/异常日志
- [ ] 错误信息已做友好处理，无敏感内容泄露

## 六、审核材料准备
- [ ] 小程序截图（首页、报修页、详情页）
- [ ] 用户协议与隐私政策链接
- [ ] 客服联系方式说明
- [ ] 版本说明/功能说明文档

## 七、上线步骤
- [ ] 体验版测试通过
- [ ] 提交审核前再次回归测试
- [ ] 审核通过后发布到线上
