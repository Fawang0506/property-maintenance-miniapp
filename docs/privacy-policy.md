# 隐私政策（示例）

在使用本小程序前，请您知悉并理解：

1. 我们会收集的内容包括：姓名、联系方式、报修位置、报修描述、图片附件、设备信息等，用于处理维修工单、跟进维修进度及通知结果。
2. 收集到的��息仅用于物业维修与工单管理，不会用于其他商业用途。
3. 图片、设备信息等内容仅在必要的维修处理范围内使用。
4. 我们会采取合理安全措施保护您的信息，避免第三方未经授权使用。
5. 如需更改隐私政策或使用范围，我们将通过小程序公告或页面提示方式通知您。
6. 若您对信息收集和使用存在疑问，可联系物业管理处或客服。

相关页面建议：
- 在小程序首次使用时弹出协议与隐私确认
- 在“我的”页面提供“隐私政策”和“用户协议”入口
- 在提交报修前展示“我已阅读并同意隐私政策”勾选项
