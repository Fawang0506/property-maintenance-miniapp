# 智能派单算法说明

本项目实现了一个轻量级智能派单策略（作演示参考），后续可根据业务需求扩展或替换为更复杂的调度策略。

基本原则：
- 优先将工单分配给技能匹配、负责该区域且当前在责工单较少的工程师。
- 考虑优先级（高/中/低），高优先级工单的优先分配权更高。

评分方法（score，值越小表示优先级越高）：
- load (当前在责工单数量) * 10
- priorityScore: 高=0, 中=5, 低=10
- skillMismatchPenalty: 若工程师技能不含工单类别，+20
- areaMismatchPenalty: 若工程师不在工单区域，+5

最终选择 score 最低者。

改进方向（建议）：
- 加入距离计算（需要工程师与工单的经纬度）
- 加入 SLA 时限与工单到期权重
- 支持多技能匹配与多工程师分配（按任务拆分）
- 使用队列+规则引擎（如优先队列）避免重复派单
